How to determine printer name and printer path

If you are using a non-network printer being shared via host PC:
  1. On the Printer Host PC (The PC where the printer is directly attached to), press “Windows + R” keys for run command line
  2. Type "cmd" on the run command line to bring out the command prompt.
  3. Type "ipconfig" to view the printer host PC’s IPV4 address. Take note of this IPV4 address.
  4. Close the command prompt (cmd) window.
  5. Press “Windows + R” keys for run command line
  6. Type the IPV4 address on step #3.
  7. You should see a list of shared folders and printers. Take note of the printer you wish to use for auto-printing document(s) on.
  8. On the data field labeled “Printer Name and Path” type the printer’s network location address and name. It should look something like this:
    \[IPV4 address of Printer Host PC, see Step #3][Printer Name shown in Step#7]
    i.e.\192.168.1.195EpsonLX300+
If you are using a network printer:
  1. Follow your printer brand’s procedure for determining your printer’s IP Address and printer name.
  2. On the data field labeled “Printer Name and Path” type the printer’s network location address and name. It should look something like this:
    \[IPV4 address of Printer][Printer Name]
    i.e. \192.168.1.190EpsonL360
